#  TOOL BONSICOLA 

## Setup Cloud (2 phút)
1. Vào https://jsonbin.io → Sign up
2. Create Bin với content: `{}`
3. Copy Bin ID từ URL
4. Dán vào `assets/js/config.js` chỗ `bin_id: "..."`
